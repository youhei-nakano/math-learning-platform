# User study protocol (not yet conducted)

**Participants:** adults currently learning or teaching undergraduate/advanced
mathematics. Exclude minors, people unable to consent, and anyone required to
upload confidential/copyright-restricted material.

**Consent summary:** This 30-45 minute study evaluates a prototype, not the
participant. AI output may be wrong. Participation is voluntary and can stop at
any time. Use only the supplied CC0 PDFs. We record task times, anonymous
responses, and observation notes; no names, contacts, raw node notes, or PDFs
are retained with study results.

## Session

1. Pre-survey (5 min): role, math background band, prior RAG/AI use.
2. Baseline task (8 min): plan prerequisites using the supplied PDF without map.
3. Tool task (15 min): inspect a generated flowchart, verify citations, write
   node notes, and identify one uncertain answer.
4. Comparison task (7 min): revise the learning order and explain why.
5. Post-survey/interview (10 min).

Rate 1-5: problem understanding, support without answer-copying, flowchart value,
node-note value, citation verifiability, uncertainty awareness, ease of use,
intention to reuse, and feasibility for teaching. Free response: confusing
steps, harmful/misleading output, most/least valuable feature, desired change.

Observer template: participant ID, timestamps, task completion, wrong turns,
help requests, citation checks, uncertainty noticed, direct quote with consent.
Interview prompts ask why ratings were chosen and when the tool should not be
used. Results schema: anonymous ID, participant band, task times, completion,
ratings, coded themes, redacted notes. Analyze medians/ranges, completion rates,
paired time differences, and two-person thematic coding where possible.

**Success criteria:** at least 70% task completion; median >=4/5 for flowchart
and citation utility; no critical privacy incident; participants detect the
seeded uncertainty in at least 60% of sessions. These are prospective criteria,
not measured results. Recruitment, contact, and data collection require separate
approval.
