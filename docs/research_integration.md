# openai-sandboxとの研究連携境界

`my-app` は学習マップ、ノード別メモ、PDF候補確認を担うブラウザUIです。
`openai-sandbox` は版固定したPDF取り込み、検索、引用検証、単一／複数役割の
評価を担う研究環境です。根拠付き質問だけは同一オリジンBFFを経由して
`POST /v1/query`へ接続します。既存のAI学習マップ候補生成先は引き続き
`math-research-assistant-portfolio` であり、経路を置き換えていません。

ノードメモは送信しません。利用者が質問欄へ入力した問題文、処理方式、固定検索設定
だけを研究APIへ渡し、返却値は
回答、引用（document/page/chunk）、実験ID、失敗状態に限定します。APIキーはサーバー側に
置き、書き込み系のフローチャート操作は別の明示確認付きAPIとして分離します。

研究用JSONLや参加者データをlocalStorageへ流し込まず、既存学習マップの保存形式を
維持することが統合時の互換条件です。
